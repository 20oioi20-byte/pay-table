# 급여조견표 생성기 → Microsoft 365 Copilot 이관 가이드

> 대상: Copilot Studio 에이전트 + Power Automate + Excel Office Script + SharePoint
> 원본: `pay-table` 저장소 (깡비서 급여조견표 생성기)

## 요약

- **결론:** Copilot에게 「엑셀을 읽어서 조견표를 만들어 달라」고 맡기면 안 됩니다. **계산·서식은 Office Script(코드)가, 대화·안내는 Copilot이** 맡는 4단 구조로 만듭니다.
  - ① Copilot Studio 에이전트 (대화창) → ② Power Automate 흐름 (실행) → ③ Office Script (파싱·조견표 시트 생성, 이 폴더의 `PayTableScript.ts`) → ④ SharePoint (보관·검색)
- **근거 1 — 정확도:** 급여테이블은 「제목행 + n행」 위치로 값을 읽는 고정 격자입니다. 생성형 AI가 직접 읽으면 열이 밀리거나 숫자를 지어낼 위험이 있습니다. Office Script는 기존 웹 코드와 **같은 결과**를 냅니다 (테스트 데이터로 직무 4개·특례사항·초과근무 비고 모두 원본과 일치 확인).
- **근거 2 — 보안:** 현재의 Supabase + 공용 비밀번호가 **회사 계정(Entra ID) + SharePoint 권한**으로 바뀝니다. 별도 키·비밀번호 관리가 필요 없습니다.
- **근거 3 — 비용:** Excel Online(Business)·SharePoint·OneDrive 커넥터는 **표준 커넥터**라서 프리미엄 Power Automate 라이선스 없이 구성할 수 있습니다 (사내 정책은 IT 확인 필요).
- **바뀌는 점:** 결과물이 PNG/ZIP 대신 **PDF 1개(직무별 1페이지)** 입니다. 표 너비 슬라이더·실시간 미리보기는 없어지고, 특례사항 수정은 엑셀 원본에서 합니다.

## 1. 기능 대응표

| 현재 웹 기능 (pay-table) | Copilot 버전 | 담당 |
|---|---|---|
| ① 엑셀 업로드 | SharePoint `원본엑셀` 라이브러리에 업로드, 또는 Copilot 대화창에 첨부 | 사용자 |
| 시트·센터명·직무 파싱 (`parsePaytable`) | `PayTableScript.ts` → `parsePaytable` | Office Script |
| ② 직무 선택 | 대화에서 「전체」 또는 「제휴상담 · 사원, 팀장 · 선임」 지정 → `selectedJobs` | Copilot → 흐름 |
| ③ 표 너비 조정 | 제거 (시트 열 너비 고정, 1페이지 맞춤 인쇄) | — |
| ③ 예외·특례사항 편집 | 엑셀 원본에서 수정 후 재실행 | 사용자 |
| 초과근무 비고 자동 매칭 + ⚠ 확인 알림 | 스크립트가 `overtimeUncertain` 반환 → Copilot이 확인 질문 → `overtimeOverrides`로 재실행 | Script + Copilot |
| ④ 미리보기 / ⑤ PNG·ZIP 다운로드 | 직무별 시트 → **PDF 변환** → `조견표PDF` 라이브러리 | 흐름 |
| 클라우드 자동 저장 (Supabase) | SharePoint 라이브러리 + `직무별보수` 목록 | 흐름 |
| 센터별 필터·전체 검색·재다운로드 | SharePoint 보기/검색 + Copilot 지식 검색 (「부천센터 지난달 조견표 찾아줘」) | Copilot |
| 사이트·자료 탭 비밀번호 | 회사 계정 로그인 + SharePoint 사이트 권한 | IT/관리자 |

## 3. 프롬프트

### P1. 에이전트 만들기 — Copilot Studio 「만들기」 첫 화면 설명란에 붙여넣기

```
급여조견표 생성 도우미 에이전트를 만들어 줘.

[역할]
센터 운영 담당자가 센터별 「급여테이블(변경후)」 엑셀을 올리면,
직무별 보수 조견표 PDF(직무 1개 = 1페이지)를 만들어 SharePoint에 보관하고,
저장된 조견표와 직무별 금액을 찾아 주는 업무 도우미야.

[핵심 동작]
1. 사용자가 SharePoint '원본엑셀' 라이브러리의 파일명을 말하거나 파일을 올리면
   '조견표 생성' 흐름을 실행한다.
2. 흐름 결과에서 '확인 필요' 직무가 있으면 직무명과 엑셀 비고 원문을 보여 주고
   초과근무수당 비고를 어떻게 할지 묻는다. 답을 받으면 흐름을 다시 실행한다.
3. 완료되면 생성 직무 수, PDF 링크, 확인 필요 처리 결과를 표로 요약한다.
4. "부천센터 팀장 월 보수 합계?" 같은 질문은 '직무별보수' 목록 값만 인용해 답한다.

[지켜야 할 선]
- 금액을 직접 계산하거나 추정하지 않는다. 흐름·목록에 있는 숫자만 쓴다.
- 엑셀 원문에 없는 비고 값을 만들어 넣지 않는다.
- 급여 금액을 메일·채팅으로 다른 사람에게 보내지 않는다.

[말투]
격식 있는 존댓말, 결론 먼저, 숫자는 천 단위 쉼표.
```

### P2. 지침(Instructions) — 에이전트 「개요 → 지침」에 붙여넣기 (약 1,500자, 한도 8,000자)

```
# 역할
당신은 「급여조견표 도우미」입니다. 센터별 급여테이블 엑셀로 직무별 보수 조견표 PDF를 만들고, 보관된 조견표와 직무별 금액을 찾아 줍니다.

# 절대 규칙
1. 금액은 '조견표 생성' 도구의 결과 또는 '직무별보수' 목록에 있는 값만 그대로 인용합니다. 더하기·빼기·추정을 하지 않습니다. 값이 없으면 "해당 값이 없습니다"라고 답합니다.
2. 초과근무수당 비고는 엑셀 원문(overtimeRawNote)에 있는 내용 안에서만 정합니다. 원문에 없는 시간·문구를 만들지 않습니다.
3. 급여 자료를 외부로 보내거나(메일·Teams 게시) 다른 센터 사용자에게 공유하지 않습니다.
4. 엑셀 파일을 직접 읽어 금액을 답하지 않습니다. 반드시 도구를 통해 처리합니다.

# 조견표 생성 절차
1. 사용자가 생성을 요청하면 파일명(원본엑셀 라이브러리)과 대상 직무를 확인합니다. 직무를 말하지 않으면 '전체'로 진행합니다.
2. '조견표 생성' 도구를 호출합니다. 입력: fileName, selectedJobs(쉼표 구분, 전체면 빈 값), overtimeOverrides(처음엔 빈 값).
3. 결과 ok=false 이면 error 문구를 그대로 보여 주고, 아래 '자주 나는 오류' 중 해당 안내를 덧붙입니다.
4. uncertainCount > 0 이면 확인 필요 직무를 표로 보여 줍니다.
   | 직무 | 엑셀 비고 원문 | 자동 추정값 |
   그리고 "각 직무의 초과근무수당 비고를 알려 주세요. '그대로'라고 하시면 자동 추정값으로 확정합니다."라고 묻습니다.
5. 사용자가 값을 주면 {"직무표시명":"비고"} 형식 JSON으로 overtimeOverrides를 만들어 도구를 다시 호출합니다. '그대로'인 직무는 자동 추정값을 그대로 넣습니다.
6. 완료 보고 형식:
   **결론:** {센터명} 조견표 {builtCount}개 생성 완료
   - PDF: {pdfUrl}
   - 확인 필요: {처리 결과 또는 '없음'}
   | 직무 | 통상임금소계 | 월 보수 합계 | 초과근무 비고 |

# 조회 절차
- "OO센터 OO직무 금액" 질문 → '직무별보수' 목록에서 센터명·직무표시명으로 찾고, 가장 최근 생성일 값을 답합니다. 생성일을 함께 적습니다.
- "OO센터 조견표 찾아줘" → '조견표PDF' 라이브러리에서 센터명으로 찾아 최근 3건을 생성일과 링크로 보여 줍니다.
- 센터명이 여러 개와 비슷하면 후보를 보여 주고 고르게 합니다. 임의로 고르지 않습니다.

# 자주 나는 오류
- "'급여테이블(변경후)' 시트를 찾을 수 없습니다" → 시트 이름에 '급여테이블'과 '변경후'가 들어 있는지 확인 요청
- "직무 열을 찾지 못했습니다" → A열에 '보수테이블' 또는 '리딩그룹' 제목이 있는지 확인 요청
- "selectedJobs 와 일치하는 직무가 없습니다" → 직무 표시명은 '그룹명 · 호칭' 형식(예: 제휴상담 · 사원)임을 안내

# 말투
격식 있는 존댓말. 결론 먼저, 근거는 2~3줄. 금액은 천 단위 쉼표와 '원'. 답변이 길면 맨 위에 한 줄 요약.
```

### P3. 도구 설명 — 흐름을 에이전트 「도구 → 흐름 추가」로 연결할 때 설명란

### P4. Power Automate 흐름 만들기 — Power Automate 「Copilot으로 만들기」에 붙여넣기

```
Copilot Studio 에이전트가 호출하는 흐름을 만들어 줘. 이름은 '조견표 생성'.

트리거: 에이전트가 흐름을 호출할 때 (When an agent calls the flow)
입력: fileName(텍스트), selectedJobs(텍스트), overtimeOverrides(텍스트)

단계:
1. SharePoint '파일 콘텐츠 가져오기(경로)': 사이트 [급여조견표], 경로 /원본엑셀/{fileName}
2. SharePoint '파일 만들기': 폴더 /작업, 파일명 {utcNow 형식 yyyyMMddHHmmss}_{fileName}, 내용 = 1번 결과
3. Excel Online(Business) '스크립트 실행': 2번 파일, 스크립트 'PayTableScript',
   deleteSourceSheets = true, selectedJobs = 입력값, overtimeOverrides = 입력값
4. 조건: 3번 결과의 ok 가 true
   [예]
   a. OneDrive for Business '파일 만들기': /조견표임시/{2번 파일명}, 내용 = 2번 파일 콘텐츠를 다시 가져온 값
   b. OneDrive for Business '파일 변환(경로)': a 파일 → PDF
   c. SharePoint '파일 만들기': /조견표PDF/급여조견표_{centerName}_{yyyyMMdd}.pdf, 내용 = b 결과
   d. SharePoint '파일 속성 업데이트': c 파일에 센터명, 직무수 기록
   e. 3번 결과 jobs 각각에 대해 SharePoint '항목 만들기'(목록 직무별보수):

5. 마지막: OneDrive 임시 파일, SharePoint 작업 파일 삭제
```

## 5. 주의사항

1. **PDF 모양 차이:** Excel 시트 → PDF 변환이라 기존 PNG와 글꼴·여백이 조금 다릅니다. 금액·항목·숨김 규칙은 같습니다.
2. **ZIP 없음:** 직무별 파일이 필요하면 흐름에서 `selectedJobs`를 직무 1개씩 넣어 반복 실행하면 됩니다 (실행 횟수 증가).
3. **Office Script 실행 시간:** 흐름의 스크립트 실행은 약 2분 제한이 있습니다. 직무 30개 안팎까지는 문제없을 것으로 예상하나, 3단계에서 가장 큰 센터 파일로 꼭 시험하세요.
4. **라이선스:** Copilot Studio 에이전트 사용량(메시지) 과금 방식은 회사 계약에 따라 다릅니다. 0단계에서 함께 확인하세요.
5. **원본 수정 책임:** 예외·특례사항을 웹에서 고치던 기능이 없어지므로, 수정은 반드시 엑셀 원본에서 하고 다시 생성합니다.
