# 급여조견표 업무 규칙 (Copilot 지식 문서)

> 이 문서는 Copilot Studio 에이전트의 **지식(Knowledge)** 으로 업로드합니다.
> 원본 시스템: 깡비서 급여조견표 생성기 (pay-table). 금액 계산·추출은 Office Script가 담당하며, 이 문서는 규칙 설명용입니다.

## 1. 목적

센터별 「급여테이블(변경후)」 엑셀을 받아 **직무별 보수 조견표**(1직무 = 1페이지)를 만들고, 센터별로 보관·검색합니다.

## 2. 입력 엑셀 구조

| 항목 | 위치 규칙 |
|---|---|
| 시트 | 이름에 `급여테이블`과 `변경후`가 모두 들어간 시트 (없으면 `급여테이블` 포함 시트) |
| 센터명 | A열에 `직무Group명` 또는 `센터명`이 있는 행의 D열 (없으면 D12 → A1) |
| 일반 블록 | A열에 `보수테이블`이 들어간 행 = 제목행 |
| 리더그룹 블록 | A열에 `리딩그룹` 또는 `리더그룹`이 들어간 행 = 제목행 |
| 그룹명 행 | 제목행 + 1 (예: 제휴상담 / 장기사고 / 교육·QA / 팀장 / Staff). 병합 셀이면 왼쪽 그룹을 이어 씀 |
| 호칭 행 | 제목행 + 2 (예: 사원 / 주임 / 선임 / 프로 / 센터장). D열부터 직무 1개 = 열 1개 |
| `비고` 열 | 직무가 아니므로 제외 |

### 제목행 기준 행 위치

| 제목행 + n | 항목 |
|---|---|
| +3 ~ +8 | 기본급, 직책수당, 직무수당, 근속수당, 급식비, 통근비 (실제 라벨은 A열 문구 사용) |
| +9 | 통상임금소계 |
| +10 ~ +15 | 업적수당 S·A·B·C·D·E (등급명은 C열, 등급 비고는 S열 +10행) |
| +16 | 초과근무수당 (비고: S열) |
| +17 | 야간근로수당 |
| +18 | 통신비 |
| +19 | 월 보수 합계 (비고: S열) |

### 예외 및 특례사항

- A열에 `예외 및 특례사항`이 있는 행부터 읽습니다.
- `1.` ~ `9.` 번호 항목은 문단, `○`로 시작하면 소제목, `10.` 이상이 나오면 끝입니다.
- 표 머리글: `구분 | 주요내용` (2열 표) 또는 `직무 | 호봉 | 근무일 | 근무시간 | 휴게시간 | 비고` (근무형태 표).

## 3. 조견표 표시 규칙

1. 제목: `[센터명 - 보수테이블]`, 부제: 일반 블록은 `○ 상담그룹`, 리더그룹은 `○ 리더그룹`.
2. 직무 표시명: `그룹명 · 호칭` (예: `제휴상담 · 사원`). 둘이 같으면 하나만.
3. 금액이 비었거나 0인 항목 행은 **숨김**. 단, `통상임금소계`·`월 보수 합계`는 항상 표시(강조).
4. 업적수당은 S~E **6개 등급을 항상 모두 표시**하고, 빈 값은 `0`으로 표시.
5. 금액은 원 단위 반올림, 천 단위 쉼표.
6. 연차 평균 사용률 표에서 값이 `1`이면 `100%`로 표시.
7. 문구 `… 적용, 80% 이상 …`은 `80% 이상` 앞에서 줄바꿈.
8. **9.근무형태 표는 해당 직무의 행만** 표시 (정확 일치 우선, 없으면 가장 유사한 직무 1행).

## 4. 초과근무수당 비고 자동 매칭

엑셀 비고 한 칸에 여러 역할이 함께 적힌 경우가 있습니다. 예: `교육 3H, 팀장 7H, 관리자 10H`

- 직무의 그룹명·호칭에 역할명이 들어 있으면 그 부분만 표시 → **확실(confident)**
  - 예: `팀장 · 선임` → `팀장7H`
- 역할이 여러 개인데 일치하는 것이 없으면 비고를 비움 → **확인 필요**
- 역할이 1개뿐인데 이름이 일치하지 않으면 그 값을 표시 → **확인 필요**
- `역할 N H` 형식이 아니면 원문 그대로 표시 → **확인 필요**
- 초과근무수당이 0이거나 없으면 비고 없음 → 확인 불필요
- **원문에 없는 값을 임의로 만들어 넣지 않습니다.** 확인 필요 직무는 담당자가 값을 정해 주면 그 값을 우선 사용합니다.

## 5. 결과물 · 보관

| 결과물 | 저장 위치 | 파일명 규칙 |
|---|---|---|
| 원본 엑셀 | SharePoint `원본엑셀` 라이브러리 | 업로드한 이름 그대로 |
| 조견표 PDF (직무별 1페이지) | SharePoint `조견표PDF` 라이브러리 | `급여조견표_{센터명}_{yyyyMMdd}.pdf` |
| 직무별 핵심 금액 | SharePoint 목록 `직무별보수` | 센터명 + 직무표시명 1행 |

## 6. 보안 원칙

- 급여 자료는 SharePoint 사이트 권한으로만 접근합니다 (회사 계정 로그인).
- 에이전트는 금액을 **계산·추정하지 않고**, `직무별보수` 목록과 생성된 PDF에 있는 값만 인용합니다.
- 다른 센터 자료는 사용자가 해당 사이트 권한을 가진 경우에만 보입니다.
