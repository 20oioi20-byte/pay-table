## 0. 한 줄 요약
보안(DRM) 급여테이블 엑셀 → 회사 M365(Power Automate + Office Script)가 값·수식을 JSON으로 변환 → 단일 HTML 시스템(v2)이 검사·조견표(PNG/ZIP)·통계·인건비 분석 보고서(Word)까지 처리.
조견표 생성·검사·M365 연동은 일단락. **다음 작업: 통계 + 보고서 정교화.**

## 1. 반드시 지킬 원칙
- 회사 급여 데이터는 외부로 나가면 안 됨. **실제 급여 파일·금액·센터명·담당자명은 Claude에 보내지 않고, 저장소·공개 문서에도 넣지 않음.** 개발·시험은 가상 데이터만 사용.
- 외부 서버(Supabase·Vercel 등)에 실데이터 저장 금지. 저장은 회사 M365(SharePoint)와 본인 PC 브라우저만.
- IT 요청(앱 등록 등) 없이 진행. 회사 DLP 통제를 우회하는 설계 금지.
- v1 시스템(index.html, dist/급여조견표_관리시스템.html, 저장소 paytable-system)은 그대로 유지. v2는 별도 파일·별도 저장소(paytable-system-v2).
- 사용자는 시스템 화면 하나에서만 작업. M365 설정은 관리자(본인)가 1회.
- 답변 스타일: 결론 먼저, 근거 2~3개, 숫자 포함, 격식체, 길면 요약 먼저.

## 4. 회사 DLP(kt is DLP) — 확인된 사실
- **OneDrive.exe가 올리는 파일 중 보안(DRM) 문서·급여 결과물(ZIP·PNG)은 '파일 반출'로 차단**, 실패 시 OneDrive가 계속 재시도(팝업 반복) → 동기화 폴더에 그런 파일을 두지 않아야 함
- 통과: html·json 업로드, 모든 내려받기, **사람이 브라우저(SharePoint 웹)로 올리는 업로드(보안 원본 포함)**
- OneDrive 앱 로그인 시 '내 파일' 전체 + 바탕화면·문서 백업이 기본 동기화 → 다른 보안 문서로도 팝업 → 보안 문서는 `C:\보안문서`로, 동기화 범위는 급여조견표만 권장
- 보안 담당: "회사 SharePoint 자동 업로드 괜찮다" → **DLP 예외 등록(OneDrive.exe → <회사 SharePoint>) 요청 예정.** 등록되면 시스템 설정에서 [자동(M365)] + [결과물 자동 보관] 켜면 완전 자동
